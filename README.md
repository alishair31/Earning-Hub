# Earning Hub - Telegram Mini App

Earning Hub is a Telegram mini app for earning through mining, referrals, and watching ads.

## Features
- Home with total balance
- Mining (Free, Silver, Gold, Premium plans)
- Referral system ($0.1 per valid referral, max 100)
- Withdrawal (USDT, $25 only)
- Profile with Telegram user info

## Tech Stack
- Frontend: HTML, CSS, JavaScript
- Backend: Coming soon (Firebase/Node.js)
- Hosting: Netlify/Vercel

## Setup
1. Clone repo
2. Open index.html
3. For Telegram integration, add your bot token and web app URL
